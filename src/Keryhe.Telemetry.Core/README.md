# Keryhe.Telemetry.Core

Domain interfaces, models and the provider-agnostic write and read plumbing for [Keryhe Telemetry](https://github.com/keryhe/telemetry).
You don't install it directly: it comes with the provider packages, `Keryhe.Telemetry.Api` and `Keryhe.Telemetry.Collector`.
